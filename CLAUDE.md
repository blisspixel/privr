# Project guidance

Follow [AGENTS.md](AGENTS.md) for all repository work.

Critical rules:

- Do not add authorship, assistant, model, or tool attribution.
- Do not use emojis.
- Do not use em dashes.
- Keep the tool local-first, free of product telemetry, conservative, and
  reversible.
- Never turn arbitrary profile or catalogue text into shell execution.
- Never report unknown or unreadable state as compliant.
- Preserve updates, encryption, and core security protections in the default
  privacy profile.
- Document sources, applicability, risks, verification, and rollback for every
  control.
- Keep formatting, lint, tests, dependency checks, cross-platform CI, and at
  least 80 percent line coverage passing.
